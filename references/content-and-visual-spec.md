# 内容与视觉规范

## 一、双栏目关系

同一主题输出两个角度：

1. 核心信号：指出一个可观察的转折、变化或分水岭，并解释判断依据。
2. 一句话判断：把该变化压缩为一个带行动含义的判断，说明应该优先做什么。

两篇可共享事实，不共享整段表达。

## 二、每日核心信号

### 图片文字结构

- 左上标签：`每日核心信号`
- 右上日期：当天 `YYMMDD`
- 主标题：两行以内，优先使用“X 的竞争，已经进入 Y”一类结构
- 解释句：3–4 个短分句，形成递进
- 主图：左侧旧阶段/演示，箭头指向右侧新阶段/生产部署
- 底部链路：4–6 个短节点，用箭头连接
- 来源：`来源：<真实来源或一宏的碎碎念>，仅供参考`

### 详情文案模板

```text
每日核心信号-YYMMDD

<一句有张力的开场，指出表象与实质的差别。>
<解释信号正在从什么转向什么，列出 3–5 个关键变化。>
<说明为什么这会改变团队、产品或组织的做法。>
<用一个问题邀请读者对照自己的场景。>

来源：<来源>，仅供参考
#话题1 #话题2 #话题3 #话题4 #话题5
```

建议 180–320 个汉字。

## 三、今日一句话判断

### 图片文字结构

- 左上标签：`今日一句话判断`
- 右上日期：当天 `YYMMDD`
- 主判断：两行以内，必须是一句完整、明确、可争辩的话
- 行动解释：3–4 行，回答“先做什么、如何验证、如何进入真实流程”
- 主图：3–4 张纸卡形成步骤链，如“选岗位 → 模拟评测 → 接入流程”
- 来源：与详情文案一致

### 详情文案模板

```text
每日一句话判断-YYMMDD

<先完整复述一句话判断。>
<解释常见误区。>
客户/团队更需要的是：
<用连续短句写出 3–4 步行动路径。>
<补充这套做法真正创造的价值。>
<以一个具体选择题式问题收尾。>

来源：<来源>，仅供参考
#话题1 #话题2 #话题3 #话题4 #话题5
```

建议 180–320 个汉字。

## 四、共同视觉规范

- 竖版 3:4，优先 1024×1536 或近似比例。
- 米白旧纸、手工撕边、淡淡纸张纤维和拼贴胶带。
- 深蓝钢笔手写字，少量黄色荧光笔划重点。
- 线稿、水彩、纸卡、便签、箭头和桌面物件组成叙事图。
- 信息层级清晰：标签与日期 → 大标题 → 解释 → 主图 → 底部链路 → 来源。
- 留出呼吸感；不要做成网页截图、黑底海报、现代 UI 面板或照片级写实。
- 禁止品牌 Logo、二维码、平台 UI、水印和无关英文。

## 五、图片生成提示词骨架

按栏目替换尖括号内容，并把参考图路径作为风格参考传入。

```text
Use case: infographic-diagram
Asset type: 小红书中文竖版知识卡片
Primary request: 生成一张“<栏目名>”手写纸张风格信息图，主题为“<主题>”
Style/medium: 米白旧纸、深蓝钢笔手写、黄色荧光笔、纸张拼贴、细线稿与淡水彩
Composition/framing: 3:4 竖版；左上栏目标签，右上 YYMMDD；中上部大标题；中部解释和叙事插图；底部步骤链与来源
Text (verbatim):
栏目：“<栏目名>”
日期：“<YYMMDD>”
主标题：“<主标题>”
解释：“<精简解释>”
步骤：“<节点1> → <节点2> → <节点3>”
来源：“来源：<来源>，仅供参考”
Constraints: 所有中文必须逐字准确、清晰可读；层级和留白接近参考图；重点词用黄色手绘下划线
Avoid: 网页界面、黑色背景、平台截图、二维码、Logo、水印、乱码、错别字、无关文字
```

生成后逐项对照 `Text (verbatim)` 验收。标题或日期错误时只针对错误文字迭代，不改动整体风格和构图。
